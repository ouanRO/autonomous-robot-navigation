



 1) Modélisation MDP pour un véhicule 2D

On définit :

Σ=(S,A,γ,Pr,cost)

-  États S

Pour un véhicule 2D, un état peut être :

s=(x,y,θ)

x = position horizontale

y = position verticale

θ = orientation

Si tu fais du Q-learning tabulaire, il faut discrétiser :

grille 2D pour (x,y)

angles discrets (ex: 8 directions)

-  Actions A

Par exemple :

Avancer

Tourner gauche

Tourner droite

Stop

Transition γ



s′=f(s,a)

Exemple :

Avancer → change (x,y)

Tourner → change θ

-  Récompense

un Exemple  :

+100 si but atteint

-100 si collision

-1 à chaque pas (encourage trajectoire courte)


2) Objectif RL

On veut apprendre :

Q(s,a)

qui approxime :

la récompense totale future attendue si on fait a en s

La politique sera :
π(s)=argamax​Q(s,a)

 ALGORITHME Q-LEARNING NAVIGATION 2D
Initialiser Q(s,a) arbitrairement (ex: 0)
Pour chaque épisode:

    Initialiser s = état initial
    
    Tant que s n’est pas terminal:
    
        Choisir action a avec stratégie ε-greedy:
            - avec probabilité ε: action aléatoire
            - sinon: a = argmax_a Q(s,a)
        
        Exécuter action a
        
        Observer:
            - nouvel état s'
            - récompense r
        
        Mettre à jour Q:
        
        Q(s,a) ← Q(s,a) 
                  + α [ r + γ max_a' Q(s',a') - Q(s,a) ]
        
        s ← s'
        
    Fin Tant que
    
    Diminuer ε progressivement
Fin Pour

la  Structure typique pour ton projet

Cycle par épisode :

Reset véhicule

Jusqu’à but ou collision :

choisir action

simuler mouvement

calculer reward

update Q

Recommencer
